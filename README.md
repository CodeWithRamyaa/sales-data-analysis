Sales Data Analysis 📊

A beginner-friendly Python project that analyzes product sales, calculates revenue, and visualizes sales performance using Pandas and Matplotlib.

🚀 Features

- Displays product sales data in a table.
- Calculates revenue for each product.
- Computes total revenue.
- Identifies the best-selling product.
- Finds the product generating the highest revenue.
- Creates a bar chart to compare revenue across products.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

📂 Project Structure

sales-data-analysis/
├── sales_analysis.py
└── README.md

📈 How It Works

Revenue is calculated using the formula:

Revenue = Units Sold × Price per Unit

The program analyzes sample sales data for laptops, phones, tablets, headphones, and keyboards.

▶️ How to Run

1. Install Python.

2. Install the required libraries:
   
   pip install pandas matplotlib

3. Run the Python program:
   
   python sales_analysis.py

You can also run the code using Google Colab.
